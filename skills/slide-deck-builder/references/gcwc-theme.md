# GCWC deck theme

Use this visual system for Getting Comfy with Claude decks. Preserve continuity with the learning hub and latest GCWC deck; do not introduce a new palette or template unless Keith asks.

## Palette

```css
:root {
  --bg: #f0ece1;
  --head: #191919;
  --ink: #33404b;
  --muted: #5c6b76;
  --accent: #2c6e8f;
  --accent-dark: #225873;
  --light: #e6eef4;
  --border: #d2dae1;
  --card: #ffffff;
}
```

Use near-black for headings, slate for body copy and blue for small accents. Reserve pale blue for section dividers, prompts and selected callouts. Use white cards only where the content is genuinely modular.

## Typography and composition

- System sans-serif; bold, tightly spaced headings; monospace for commands and prompts.
- Warm cream canvas, generous margins and strong back-row contrast.
- Prefer one dominant composition per slide: large type, a simple flow, a screenshot, a comparison or a small card group.
- Avoid turning every slide into a grid of interface panels.
- Use subtle borders and shadows; keep rounded corners restrained and consistent.

## Programme continuity

- Brand line: `Getting Comfy with Claude · 201`.
- Keep section labels, slide count and presenter cues in consistent positions.
- Use pale-blue divider slides at major block boundaries.
- Reuse the latest real attendance QR, screenshots and programme assets when available.
- Match existing component classes when editing or extending an earlier GCWC deck.

Design on a scalable 16:9 stage unless the venue requires another ratio. The theme is complete when the deck looks like the learning hub at presentation scale rather than a separate product.
